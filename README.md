# João Victor Mendonça

Desenvolvedor **Full Stack** e estudante de **Ciência da Computação na Universidade Federal Rural de Pernambuco (UFRPE)**, com experiência no desenvolvimento de aplicações web, APIs, automação de processos e integração de recursos de **Inteligência Artificial**.

Atualmente atuo com desenvolvimento de software no **Instituto SENAI de Inovação para Tecnologias da Informação e Comunicação**, trabalhando principalmente com aplicações baseadas em **Python, FastAPI, React/Next.js, PostgreSQL, Docker e soluções com IA Generativa**.

Tenho interesse especial em desenvolvimento **Full Stack**, arquitetura de aplicações e Inteligência Artificial, explorando também tecnologias como **RAG, agentes de IA e MCP**.
